    复现路线

    从一台空机器到能自己走的四步。每一步都有明确的产物，能验收再往下走。

    STEP 01

    环境：Docker 跑仿真

    daemon 用真的，身体换成 MuJoCo。一条命令起一只鸭子，控制环必须跑到实时， 否则策略等于在慢动作里训练。

    scripts/duck-sim
    STEP 02

    训练：从任务到 checkpoint

    mjlab + MuJoCo Warp，PPO，数千环境并行。奖励、观测、域随机化都在任务配置里， 改这三样才叫改任务。

    uv run train Mjlab-VelStand-Rough-Backlash-MicroDuck
    STEP 03

    导出：checkpoint → ONNX

    归一化器必须烘进计算图，手转会漏。导出后用真实观测对一遍数值， 这一步错了真机上表现为“抖动但能站”。

    uv run scripts/export.py <task> --checkpoint ...
    STEP 04

    部署：装到真机

    策略进槽位，先回 home 再热切换。装错了也能回滚： 更新引擎是验签 + 切目录 + 健康门禁，失败自动退回上一版。

    robotctl policy load walk <repo>

    主步态：站立、行走、转向、被推倒后自己爬起来，是同一个策略。

    Sit ↔ Stand

    姿态槽位，坐下之后仍然接受头部指令。

    Official set

    Ground Pick

    低头捡物：喙触地、闭合、起身。轮滑模式下换成蹲下。

    Doc Curves

    1024 环境 × 200 迭代的短程训练，用来对照“正常曲线长什么样”。
