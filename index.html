      复现

      从一台空机器，到能自己走。

      1. 01

        环境

        Docker 里的 MuJoCo，跑的是真 daemon，不是替身。

        scripts/duck-sim
      2. 02

        训练

        mjlab + PPO，4096 个环境并行，奖励与随机化都在任务配置里。

        uv run train Mjlab-VelStand-Rough-Backlash-MicroDuck
      3. 03

        导出

        checkpoint 转 ONNX，归一化器一起带走——这一步错了真机上就抖。

        uv run scripts/export.py <task>
      4. 04

        部署

        装进槽位，先回 home 再切换。装错了也能回滚到上一版。

        robotctl policy load walk <repo>

      策略

      官方策略集，和本机跑出来的结果。

      1. 01 VelStand Official · v8 站立、行走、转向、被推倒后自己爬起来，是同一个策略。
      2. 02 Sit ↔ Stand Official set 姿态槽位，坐下之后仍然接受头部指令。
      3. 03 Ground Pick Official set 低头捡物：喙触地、闭合、起身。轮滑模式下换成蹲下。
      4. 04 Doc Curves Local run 1024 环境 × 200 迭代的短程训练，用来对照“正常曲线长什么样”。
